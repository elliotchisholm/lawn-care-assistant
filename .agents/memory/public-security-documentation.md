name: Public security documentation
description: Publication boundaries for security reviews in this public repository.
---

This repository is public. Uploaded private security reviews and
deployment-specific lists of open findings must not be committed. Public
security documentation should provide general contributor guidance instead.

**Why:** The user identified accidental publication of their security review
and asked to remove it and check the public hardening document.

**How to apply:** Before committing uploaded review material or security
documentation, check its intended audience. Keep sensitive assessment details
out of public files, including agent memory. Removing material from the current
tree is not history erasure; the user accepted retained history for these reviews.
